# نصیر VPN (Nasr VPN) — افزونهٔ Chrome مدیریت سابسکریپشن پروکسی

افزونهٔ Manifest V3 برای دریافت سابسکریپشن‌های پروکسی، نمایش سرورها و تأخیر آن‌ها، و اعمال پروکسی سازگار در Chrome.

## امکانات
- دریافت سابسکریپشن از لینک با فرمت‌های: Base64/URI، Clash Meta (ساده)، sing-box/V2Ray JSON
- نمایش سرورها با پروتکل، نام، میزبان/پورت
- اندازه‌گیری «زمان پاسخ HTTP» به‌عنوان معیار تأخیر (نه پینگ ICMP)
- اعمال پروکسی با `chrome.proxy` فقط برای HTTP/HTTPS/SOCKS4/SOCKS5
- به‌روزرسانی خودکار زمان‌بندی‌شده (chrome.alarms)
- ذخیرهٔ تنظیمات در `chrome.storage.local`، پاک‌سازی کامل داده‌ها
- رابط فارسی راست‌چین

## محدودیت‌های فنی (مهم)
- پروتکل‌های VLESS/VMess/Trojan/Shadowsocks **توسط chrome.proxy پشتیبانی نمی‌شوند**؛ این سرورها فقط شناسایی و ذخیره می‌شوند. برای اتصال به آن‌ها کلاینت محلی سازگار (مثل هستهٔ sing-box یا v2ray) لازم است و پس از اجرای آن می‌توان SOCKS5 محلی را در افزونه انتخاب کرد.
- «تأخیر» نمایش‌داده‌شده زمان پاسخ HTTP است و تضمینی برای سرعت/امنیت/ناشناس‌سازی نیست.
- احراز هویت پروکسی (user/pass) در این نسخه پشتیبانی نمی‌شود.
- هدر `Subscription-Userinfo` (مصرف/حجم) در نسخهٔ فعلی نمایش داده نمی‌شود.

## ساختار
| فایل | نقش |
|---|---|
| `manifest.json` | پیکربندی MV3 (permissions: proxy, storage, alarms) |
| `src/parsers.js` | parserهای سابسکریپشن (Base64/URI/Clash/sing-box) |
| `src/background.js` | سرویس‌ورکر: دریافت، اعمال پروکسی، تست تأخیر |
| `popup/` | رابط پاپ‌آپ (نمایش/انتخاب سرور) |
| `options/` | تنظیمات (لینک ساب، فرمت، refresh، timeout) |

## راهنمای نصب (Unpacked Extension)
1. مخزن را Clone یا به‌صورت ZIP دانلود و از حالت فشرده خارج کنید.
2. Chrome → `chrome://extensions` را باز کنید.
3. گوشهٔ بالا، **Developer mode** را روشن کنید.
4. **Load unpacked** → پوشهٔ پروژه را انتخاب کنید.
5. آیکون افزونه را باز کنید → «تنظیمات» → لینک سابسکریپشن را وارد و ذخیره کنید.
6. در پاپ‌آپ روی «به‌روزرسانی» بزنید؛ سرورها لیست می‌شوند. روی سرور دلخواه کلیک کنید تا پروکسی اعمال شود (فقط HTTP/HTTPS/SOCKS).

> نکته: در این نسخه فیلد `icons` در manifest حذف شده است تا Load unpacked بدون خطا کار کند. پس از افزودن فایل PNG آیکون، فیلد را دوباره اضافه کنید.

## امنیت و حریم خصوصی
- بدون `eval` و بدون remote code؛ فقط ماژول‌های محلی.
- **لینک سابسکریپشن (شامل توکن) همیشه ماسک‌شده نمایش داده می‌شود** (پروتکل و دامنه نمایان، مسیر/پارامترها به‌صورت `****`)؛ نمایش کامل فقط با دکمهٔ «نمایش لینک».
- «حذف لینک» و «پاک‌سازی کامل داده‌ها» کلیدهای مربوطه را فوراً و امن از `chrome.storage.local` پاک می‌کنند.
- توکن/اعتبارنامه‌ها در لاگ یا رابط افشا نمی‌شوند.
- CSP پیش‌فرض MV3 (بدون inline script).

## مجوزها
| مجوز | دلیل |
|---|---|
| `proxy` | اعمال/حذف پیکربندی پروکسی |
| `storage` | ذخیرهٔ تنظیمات و لیست سرورها |
| `alarms` | به‌روزرسانی خودکار زمان‌بندی‌شده |
| `host_permissions: <all_urls>` | لازم برای (۱) دریافت سابسکریپشن از هر دامنهٔ ارائه‌دهنده و (۲) تست تأخیر مستقیم به host:port هر سرور موجود در ساب. چون دامنه‌ها از سابسکریپشن کاربر به‌صورت پویا می‌آیند، فهرست ثابت دامنه ممکن نیست؛ بنابراین `<all_urls>` نگه داشته شده است. این مجوز فقط برای fetch خواندنی/تست استفاده می‌شود و هیچ داده‌ای به سرور سوم ارسال نمی‌شود. |
